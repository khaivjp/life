# KhaiLife

## Thay logo

Website sử dụng **một ảnh duy nhất** ở `assets/icons/logo.png` làm logo thanh bên, favicon của trình duyệt và biểu tượng khi thêm web vào màn hình chính iPhone.

1. Chuẩn bị ảnh PNG **vuông** (nên dùng 512 × 512 px).
2. Trong GitHub, mở `assets/icons/logo.png`, chọn **Upload files** để tải ảnh mới lên và ghi đè bằng đúng tên `logo.png` (hoặc thay ảnh từ máy tính rồi commit).
3. Đợi GitHub Pages triển khai xong, tải lại website. Favicon có thể bị lưu cache. Biểu tượng đã ghim trên iPhone có thể phải xóa shortcut rồi thêm lại mới cập nhật.

Không cần thay đường dẫn trong HTML/CSS khi đổi logo.

**Lưu ý:** Repo và website công khai, nên chỉ dùng ảnh bạn muốn công khai.
